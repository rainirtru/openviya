# API contracts

The versioned application API uses `/api/v1`. Health endpoints are operational probes and are not part of the public business API.

Staff password/TOTP, owner-only staff management, and one-time owner recovery are documented in [staff-auth.md](staff-auth.md). Telegram OIDC login is documented in [telegram-auth.md](telegram-auth.md). Other business API contracts will be added together with their application flows.
