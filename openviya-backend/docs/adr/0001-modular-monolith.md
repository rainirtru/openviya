# Модульный монолит и PostgreSQL

Для запуска OpenViya с ориентиром в 50 пользователей и 4–5 VPN-локаций принято одно Java + Spring приложение с одной PostgreSQL-базой и внутренними модулями, разделенными по обязанностям. Интеграции с центрами управления, платежными сервисами и Happ оформляются отдельными адаптерами, чтобы добавление провайдера не меняло коммерческую модель подписки. Такая структура сохраняет границы ответственности и возможность последующего выделения модулей, ограничивая начальную сложность развертывания и согласования данных между отдельными сервисами.
