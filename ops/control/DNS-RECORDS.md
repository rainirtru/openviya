# DNS для openviya.online

В DNS-панели Timeweb для зоны `openviya.online` сейчас добавить:

| Тип | Поле «Хост» / поддомен | Полное имя | Значение | TTL |
| --- | --- | --- | --- | --- |
| A | `api` | `api.openviya.online` | `31.44.7.93` | `600` |

Если форма Timeweb ожидает полный хост, указать `api.openviya.online`; если домен уже приписан формой — только `api`. В значение вводится только IPv4, без `https://`, порта и пути. Для первой проверки использовать прямую A-запись без CDN-проксирования. AAAA пока не добавлять: IPv6 для веб-сервиса не настроен.

Это единственная новая обязательная запись для уже развёрнутого backend. Она нужна для HTTPS и Telegram OIDC. На VPS каждые пять минут проверяется DNS, после совпадения адреса автоматически включается Caddy HTTPS. Фактическую выдачу сертификата необходимо проверить после распространения записи.

На скриншоте уже есть следующие записи — их адреса сохраняются:

| Тип | Хост | Значение |
| --- | --- | --- |
| A | `panel-ca-1` | `45.133.19.34` |
| A | `panel-usa-2` | `31.44.7.190` |
| A | `usa-2` | `31.44.7.190` |

Для VPN-ноды Канады по принятой схеме также требуется `A ca-1 → 45.133.19.34`, **если это тот же VPS, на котором размещена её панель, и такая запись ещё не создана**. На скриншоте записи `ca-1` не видно. Запись только `panel-ca-1` не создаёт VPN-имя автоматически. DNS сам по себе не создаёт inbound и не подключает ноду к центральной панели.

Управляющая панель на `31.44.7.93` открывается через SSH-туннель и публичной DNS-записи не требует. Имена `panel-control`, корень домена, `www`, `app`, `admin` и `sub` сейчас добавлять для этого развёртывания не требуется: отдельные публичные сайты и subscription gateway ещё не опубликованы.

Существующие MX и TXT/SPF корня домена относятся к почте, они не препятствуют новой A-записи `api`. Сохраняйте их. TXT/SPF у VPN-поддоменов также не требуется менять для этой настройки. Записи должны создаваться у DNS-провайдера, чьи NS авторитетны для домена.
